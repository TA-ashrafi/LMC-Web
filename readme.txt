# Features
- Fully responsive design built with CSS grid and flexbox.
- Built-in Customizer options to edit agency services, hero banner, portfolio, clients, story, and footer content without code.
- Custom navigation support with preconfigured service dropdown items:
  * Our Social Media Services
  * Content Creation
  * Photography & Videography
  * Performance Marketing
  * Influencer Marketing
  * Website Development
  * Brand And Packaging Design
- Dynamic CTA header button ("Talk To Our Team").
- Full template support for single posts, static pages, archives, search results, 404, and comments.

# Installation
1. Compress the theme folder into `lemon-media-company.zip`.
2. Go to WordPress Admin -> Appearance -> Themes -> Add New -> Upload Theme.
3. Select the zip file and click "Install Now".
4. Activate "Lemon Media Company".
5. Customize via Appearance -> Customize.
